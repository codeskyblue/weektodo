WeekTodo 隐私政策

生效日期：2026 年 11 月 7 日

WeekTodo 是一款离线优先的周任务管理应用。我们不会收集、上传或出售你的个人信息和任务数据。

数据存储

  • 任务、分类、设置和数据备份保存在你的设备本地（应用沙盒）。
  • 应用不需要注册账号，也不包含广告、分析 SDK 或跨应用跟踪。
  • 删除应用或在应用内清除数据后，本地数据会被删除。

可选功能

  • AI 润色：只有在你主动配置 OpenAI 兼容接口和 API Key 后才会使用。启用后，当前周报的文本会发送到你配置的接口。开发者不会收到这些内容，也不会保存你的 API Key 到服务器。
  • WebDAV 同步：只有在你主动配置服务器后才会使用。应用会把任务数据发送到你指定的 WebDAV 服务器。服务器地址、用户名和密码保存在本机。

数据共享

除上述由你主动配置的服务外，应用不会向任何第三方传输数据。开发者不收集、不存储、不出售你的数据。

儿童隐私

应用不面向儿童收集任何个人信息。

政策变更

如果本政策发生重大变更，我们会更新本页面并修改生效日期。

联系我们

如有问题，请通过 GitHub Issues 联系开发者。

Privacy Policy

Effective date: November 7, 2026

WeekTodo is an offline-first weekly planner. We do not collect, upload or sell your personal information or task data.

Data storage

  • Tasks, categories, settings and backups are stored locally on your device.
  • No account is required. The app contains no ads, analytics SDKs or cross-app tracking.
  • Deleting the app or clearing data in the app removes the local data.

Optional features

  • AI polish: only used after you configure an OpenAI-compatible endpoint and API key. When enabled, the current weekly report text is sent to the endpoint you configure. The developer does not receive this content or store your API key on a server.
  • WebDAV sync: only used after you configure a server. The app sends task data to the WebDAV server you specify. The server address, username and password are stored locally.

Data sharing

Other than the services you explicitly configure, the app does not transmit data to any third party. The developer does not collect, store or sell your data.

Children's privacy

The app does not collect personal information from children.

Changes

If this policy changes materially, we will update this page and the effective date.
