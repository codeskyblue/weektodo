## 描述

WeekTodo 是一款以周为单位的离线任务管理工具，帮助你专注本周、回顾上周、规划下周。

主要功能：

• 周视图：支持 1 / 2 / 3 周并排查看，快速切换上一周和下一周
• 任务管理：子任务、日期安排、完成、废弃、拖动排序
• 分类：为工作、生活等场景建立独立任务列表
• 周报：一键生成本周完成情况，可选 AI 润色
• WebDAV 同步：与桌面版或其他设备同步数据
• 外观：浅色、深色、跟随系统，支持中英文
• 离线优先：数据保存在本机，无需注册账号

AI 润色是可选功能，使用你自己配置的 OpenAI 兼容接口和 API Key。WebDAV 同步同样使用你自己的服务器。开发者不收集你的任务数据。
